# Dokumentasi IndoWater

Selamat datang di dokumentasi IndoWater. Dokumentasi ini berisi informasi lengkap tentang sistem manajemen meter air prabayar IndoWater.

## Struktur Dokumentasi

Dokumentasi ini terbagi menjadi tiga bagian utama:

1. **Manual Pengguna**: Panduan penggunaan aplikasi untuk berbagai peran pengguna.
2. **Dokumentasi API**: Referensi lengkap API IndoWater untuk integrasi sistem.
3. **Dokumentasi Pengembang**: Panduan teknis untuk pengembang yang bekerja pada sistem IndoWater.

## Manual Pengguna

Manual pengguna berisi panduan langkah demi langkah untuk menggunakan aplikasi IndoWater, tersedia untuk tiga peran pengguna utama:

- [Manual Pengguna - Pelanggan](user-manuals/pelanggan.md): Panduan untuk pelanggan yang menggunakan aplikasi mobile untuk mengelola meter air mereka.
- [Manual Pengguna - Admin](user-manuals/admin.md): Panduan untuk administrator sistem yang mengelola pengguna, meter air, dan transaksi.
- [Manual Pengguna - Teknisi](user-manuals/teknisi.md): Panduan untuk teknisi lapangan yang melakukan instalasi, pemeliharaan, dan perbaikan meter air.

## Dokumentasi API

[Dokumentasi API](api-documentation/README.md) berisi referensi lengkap untuk API IndoWater, termasuk:

- Autentikasi dan otorisasi
- Endpoint API
- Format permintaan dan respons
- Contoh penggunaan
- Webhook
- Integrasi dengan sistem pihak ketiga

## Dokumentasi Pengembang

[Dokumentasi Pengembang](developer-documentation/README.md) berisi informasi teknis untuk pengembang yang bekerja pada sistem IndoWater, termasuk:

- Arsitektur sistem
- Lingkungan pengembangan
- Panduan backend (API)
- Panduan frontend (web)
- Panduan mobile (Android & iOS)
- Skema database
- Integrasi pihak ketiga
- Keamanan
- Pengujian
- Deployment
- Pemeliharaan
- Panduan kontribusi

## Cara Menggunakan Dokumentasi Ini

1. **Pengguna Baru**: Mulailah dengan membaca manual pengguna yang sesuai dengan peran Anda.
2. **Pengembang Integrasi**: Baca dokumentasi API untuk memahami cara mengintegrasikan sistem Anda dengan IndoWater.
3. **Pengembang Sistem**: Baca dokumentasi pengembang untuk memahami arsitektur dan cara berkontribusi pada sistem IndoWater.

## Pembaruan Dokumentasi

Dokumentasi ini diperbarui secara berkala untuk mencerminkan perubahan dan peningkatan pada sistem IndoWater. Tanggal pembaruan terakhir: 30 Juli 2025.
